Round-3 redaction rules (tasks #343 #336 #345 #346 #347, swarm run 20261105-d18b04, 2026-11-06, branch feature/jev-integrations). (1) Never transform text ahead of the redactor: compaction.ts readablePaths() now runs redact() on the whole text first, with pure filesystem-path tokens (FS_PATH: no ://, //, @, =, ?, %, :) swapped for private-use placeholders n that are restored as shortened, per-segment-redacted paths; a placeholder the redactor masked is never restored; root prefixes are stripped after. (2) redact.ts: scheme-less `user:pass@host` / `//user:pass@host` rule (bounded {0,64}/{1,128}, linear), user-only URL tokens of 16+ chars (`https://<token>@`), isSecretName accepts plurals (tokens, api_keys, keys) unless the word before is a count word (max_tokens, prompt_tokens, num_keys); clean() is exported. (3) diff-redact.ts finds a secret name ANYWHERE on a line (secretAt): subscripts, `: Type =`, ?= ||= ??= += -= := => == <<<, $/@ sigils, `fn('NAME', v)`, secret-named calls `SetBasicAuth(`, C# `{ get; set; } =`, markdown `**k**:`, keyword-space forms (Dockerfile ENV/ARG/LABEL, #define, setenv, set), SQL PASSWORD/IDENTIFIED BY/INSERT (…password…) VALUES/INSERT INTO api_keys; redaction runs from the operator to end of line, continuation from the value proper. Trailing binary operators and comment lines carry a value on. YAML roots are column-0 mapping keys or --- (not `- item`); an empty-valued secret key owns a compact list/stray scalar at its own column; `name: <secret>` masks its sibling `value:` in either order (YAML/JSON, one-line flow too); YAML data:/stringData: children masked; any `kind: Secret|SealedSecret` line in a hunk drops the file. TOML [table] with a secret segment masks every value to the next header; TOML keys of a table above the hunk (hunk not at line 1) and JSON keys indented >2 before a top-level key keep names, lose values unless SAFE_VALUE (small numbers, booleans, version strings). (4) Deny: DIFF_DENY_FLOOR always; DIFF_DENY_NAMES (secrets.*, credentials*, *kubeconfig*, passphrase*, recovery/backup codes, seed phrase, jwtkey...) except for SOURCE_MODULE extensions (ts/js/py/go/rs/java/kt/swift/c/cpp/cs/scala), so src/adjudicator/secrets.ts is sent (values line-scrubbed) while secrets.php/.sh/.json are not; compound secret dir words (my-secrets/, secrets-prod/, sealed-secrets/, prod_credentials/, api-keys/); fixed app secret stores (wp-config*.php, LocalSettings.php, local_settings.py, appsettings*.json, local.settings.json, serviceAccountKey*.json, docker/config.json, .azure/, gcloud/...). Every path a section names (git header splits, ---/+++, rename/copy from/to, C-quoted) must be allowed; unparsable quoting skips the file. COMMIT_EXCLUDE stays at 64 globs (user cap), names only with data extensions. Cost on this repo (141 commits): no extra data file emptied, 0 commits emptied.
