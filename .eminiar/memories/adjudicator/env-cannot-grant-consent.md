Adjudicator: environment variables can only WITHDRAW remote consent (task #48, swarm run 20261104-483f39, 2026-11-04, branch feature/adjudicator; supersedes the "env" path of adjudicator/remote-consent-origins). Threat: Claude Code applies a trusted project's .claude/settings.json `env` block to the session and its hooks, so a cloned repo could set EMINIAR_ADJUDICATOR=1 + EMINIAR_ADJUDICATOR_PROVIDER=typesafe|openai-compatible + EMINIAR_ADJUDICATOR_REMOTE=1 and send prompts to a built-in host with the user's stored key. Rules now: src/config.ts envOverrides sets remoteConsent=false only for EMINIAR_ADJUDICATOR_REMOTE=0 (=1 is ignored); src/adjudicator/config.ts ConsentVia is "config" | "legacy" (no "env"); consentFor returns "config" when the origin is in personal remoteConsentOrigins, "legacy" only for remoteConsent:true with NO list, a built-in origin AND env.EMINIAR_ADJUDICATOR_PROVIDER unset (a legacy consent never follows a provider the env swapped in); else undefined → no_consent. EMINIAR_ADJUDICATOR=1 may still turn the feature on; EMINIAR_ADJUDICATOR_PROVIDER may pick a remote provider that runs only if remoteConsentOrigins already lists its origin. Tests that need consent must write remoteConsent/remoteConsentOrigins to $EMINIAR_HOME/config.json (legacy remoteConsent:true still works when the PROVIDER env var is unset). Regression test: tests/unit/adjudicator-hooks.test.ts "a project .claude/settings.json env block cannot grant remote consent (#48)" — key file holds keys, no personal consent, globalThis.fetch stubbed to a local 127.0.0.1 stub server recording every request, asserts nothing fetched for PROVIDER=groq/openai-compatible/typesafe, plus a legacy-consent case and a positive control (origin listed → request reaches the stub with the Bearer key; REMOTE=0 withdraws). Same task: AdjudicatorStore.byToolUseId(id,{surface,since}) with index adjudications_tool_use (in v8 DDL and ADJUDICATOR_LATE_INDEXES healed by healAdjudicatorColumns), used by hooks.ts onPostAgent instead of scanning 200 rows; tryItStore passes `atomically` through.
