Adjudicator: the personal config is anchored to the OS account (task #54, swarm run 20261104-483f39, 2026-11-04, branch feature/adjudicator; extends adjudicator/env-cannot-grant-consent). Threat: a trusted project's .claude/settings.json `env` block can set EMINIAR_HOME (or HOME, which os.homedir() reads) to a folder inside the repo, so a config.json the repo ships became the "personal" config (consent, custom baseUrl, keyEnv=GITHUB_TOKEN → token exfiltration). Rule: src/config.ts personalConfigTrusted(projectRoot, file = paths().configFile): a file directly in <os.userInfo().homedir>/.eminiar (user database, not $HOME) is always trusted; any other location only if its realpath (realpathSync.native; case-insensitive compare on darwin/win32; nearest existing ancestor for a file not yet written) is outside projectRoot, process.cwd() and every git work tree of either (read from .git file/gitdir/commondir/worktrees/*/gitdir, no git spawn). loadConfig's personalLayer() gives an untrusted personal file the project layer's cut (only PROJECT_ADJUDICATOR_KEYS survive); the check runs only when the file sets other adjudicator keys. projectAdjudicatorWarning(root) also returns "adjudicator.X, … ignored: <file> is inside this project (EMINIAR_HOME or HOME points into it)…" first (joined with " · "), so doctor/status/dashboard need no change. CLI personalFileUntrusted(): enable (unless --project only), provider <x>, key set (--from-env and stored, the latter checks paths().adjudicatorKey) and install setup refuse (exit 1, nothing written). Tests with a temp EMINIAR_HOME outside the project root keep working. Same run: #55 CLI `previous` origin = personalOrigin(root) parsed from ~/.eminiar/config.json alone with env {}; withConsentedOrigin(a, origin) lost `previous` — a migration writes only the origin the notice named. #56 tiers max 4 unique, weights records bounded, buildCatalogue caps roles at MAX_ROLES=16 with identifier names. #57 cli.ts valueLooksLikeKey / baseUrlProblem / argvKeyProblem refuse key-shaped --model/--since/--fixture/--repeat/--providers and --base-url with userinfo, fragment, secret-named or key-shaped query/path, before config loads, never echoing. Regression tests: adjudicator-hooks "EMINIAR_HOME or HOME pointed into the project cannot grant consent (#54)", adjudicator-config "the personal config's trust anchor (#54)" and "lists sent to providers are bounded (#56)", adjudicator-cli #54/#55/#57/#59 tests.
