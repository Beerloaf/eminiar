Adjudicator end-to-end verification (task #20 / T15, swarm run 20261104-483f39, 2026-11-04). tests/integration/adjudicator.test.ts (28 tests) drives the BUILT artifacts (bin/em-hook -> dist/hook.js, bin/eminiar -> dist/cli.js, bin/em-server -> dist/server.js, `eminiar ui`) in real child processes, one scratch EMINIAR_HOME + project per scenario, with a local HTTP Jev stub (POST /v1/systemone, GET /v1/models) via typesafe.baseUrl. Run `npm run build` first. Facts learned: (1) the project layer is an allowlist (#32), so tests must put timeouts/breaker/provider/keyEnv in $EMINIAR_HOME/config.json (helper globalConfig), never eminiar.config.json; (2) a loopback endpoint gets only a key-FILE entry, never an env key, so an env-key e2e needs a non-loopback host (0.0.0.0:<stubport> works) plus `provider typesafe --base-url U --accept-remote`; (3) `adjudicator test` deliberately calls the provider even with EMINIAR_ADJUDICATOR=0; (4) eminiar's own session capture (sessions/events tables) stores raw prompts by design, so prompt-text leak checks look at the adjudicator tables + non-DB files only, while the API key is scanned in every byte of EMINIAR_HOME (DB, WAL, SHM, hook.log); (5) the detached --adjudicate child's stdin is captured by a wrapper script used as the hook script (argv[1]); (6) concurrent `npm run build` runs by several workers race on dist/ (hook.js can vanish): rebuild alone before running the suite. scripts/bench-hotpath.mjs gained hook cases: `node scripts/bench-hotpath.mjs --only hooks --hook-runs 100 --base <checkout of 6db2683 built with npx tsup, node_modules symlinked> --assert` (budgets: adjudicator off <= 1 ms p50 over base; enabled heuristic UserPromptSubmit <= 150 ms p95). Measured (100 interleaved real-process runs, M-series): prompt off 51.9 vs base 52.6 ms p50, Bash off 52.8 vs 53.2, enabled heuristic prompt p50 66.5 / p95 78.9, Agent p50 69.5 / p95 84.6; breaker-open call 0.05 ms vs heuristic-only 0.03 ms p50.
