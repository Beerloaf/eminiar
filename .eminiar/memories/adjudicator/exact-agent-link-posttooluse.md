Exact Agent dispatch → subagent link (branch feature/adjudicator, swarm run 20261104-483f39, task #47, 2026-11-04). Verified against real transcripts (~1000 Agent results across 257 sessions) and code.claude.com/docs/en/hooks.md: PostToolUse(Agent) `tool_response` is the tool's structured output (== transcript toolUseResult). Both shapes carry `agentId` (bare id like "af53afe7161b11a15", the same value sidechain transcript entries put in agentId, so api_calls.agent_id) and `resolvedModel` (model the subagent STARTED on): background `{status:"async_launched", agentId, description, prompt, outputFile, resolvedModel, isAsync, canReadOutputFile, canContinueAgent?}` and foreground `{status:"completed", agentId, agentType, content, resolvedModel, totalTokens, totalDurationMs, totalToolUseCount, usage, toolStats, modelsUsed? (only on a mid-run swap), handback?}`. A rejected call gives a string, sometimes no response. `<transcript dir>/<session>/subagents/agent-<id>.meta.json` has `toolUseId` too. Implementation: src/hooks/capture.ts postToolUse (now async) lazily imports onPostAgent from src/adjudicator/hooks.ts only for Agent/Task, adjudicator.enabled and client != cursor. onPostAgent (surfaces.agent gated, never throws) reads agentLinkOf(input) (tool_response.agentId, else the meta.json scan), finds the agent-surface row with the same tool_use_id among the newest 200 of the last 24 h (local DB, then the coordination root's DB for worktree workers), and sets agentId (only when the row has none; a differing existing id is logged, kept) plus actualModel = resolvedModel when the row has none (reconcile's pricePatch overwrites it from the subagent's own api_calls when they exist). learn.ts unchanged: reconcile already prefers row.agentId, so parallel same-tier dispatches that matchDispatches must leave ambiguous are now linked exactly. Verdict (types.ts) now has `heuristicComplexity?: number`; engine.ts EngineVerdict was removed (unified into Verdict).
