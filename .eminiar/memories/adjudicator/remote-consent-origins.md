Adjudicator remote consent is bound to an origin (task #33, swarm run 20261104-483f39, 2026-11-04, branch feature/adjudicator; implements rule 2 of constraint adjudicator/project-layer-trust-boundary). Config: adjudicator.remoteConsentOrigins (optional string[], personal ~/.eminiar/config.json only, not in PROJECT_ADJUDICATOR_KEYS) next to the remoteConsent master flag. src/adjudicator/config.ts: originOf(url) = URL.origin (scheme+host+non-default port, http/https only); BUILTIN_REMOTE_ORIGINS = groq, cerebras, typesafe default (https://api.groq.com, https://api.cerebras.ai, https://api.typesafe.ai); consentFor(a, origin, env) returns "config" (origin listed) | "env" (EMINIAR_ADJUDICATOR_REMOTE=1 and a built-in origin) | "legacy" (remoteConsent true with NO list, built-in origins only) | undefined; EMINIAR_ADJUDICATOR_REMOTE=0 or remoteConsent false revokes all. resolveAdjudicator reads opts.env for the env flag and sets Resolved.origin/consent/consentVia; every remote path (engine gate, hooks, eval candidates, CLI test/probe, dashboard) goes through it, so no engine.ts change was needed. DECISION: the env var never consents to a custom baseUrl (it names no host and a project .claude/settings.json env block may set it). CLI (src/adjudicator/cli.ts): mustAsk() asks whenever the target origin is not covered or only a legacy consent covers a different origin; consentPatch() writes remoteConsent:true + withConsentedOrigin(personal file list, origin, previousOrigin) (legacy configs migrate the previously configured origin; an env-only grant is not written). Notices/questions name the origin ("is sent to https://api.groq.com"). providers/http.ts fetches with redirect:"manual" and turns every 3xx (or opaqueredirect) into http_error "redirect to <host/path> refused", so a 3xx never re-sends text or key. Tests: adjudicator-config "remote consent is bound to an origin (#33)", adjudicator-cli "consent is bound to the origin the notice named (#33)", adjudicator-providers "redirects are never followed (#33)" (real local 307 server).
